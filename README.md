**Speak. Your words appear where you type.**

[Download for Windows](https://github.com/perikx/apollo-s2t/releases/latest) · [MIT](LICENSE)

Download `apollo.exe` and run it. Setup asks for your [OpenRouter key](https://openrouter.ai/keys). API usage is paid from your OpenRouter balance.

| Key | Action |
| --- | --- |
| F8 | Dictate |
| F9 | Clean up, preserving your words and repetitions |
| F10 | Build a prompt |

Press once to record, again to stop. Change keys, models and fallback in the app. Failed transcriptions can be retried from Recovery.

Audio and text are sent through OpenRouter. Recovery is cached locally; configuration can contain your API key.
